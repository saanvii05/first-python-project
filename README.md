
# Python Quiz Application 🎯

## About
This is a beginner-friendly Python Quiz Application that asks users 5 basic questions about Python programming and general mathematics.

The program checks the user's answers, calculates their score, and displays a final message based on their performance.

## Features
- Displays 5 quiz questions.
- Accepts answers from the user.
- Checks whether answers are correct or incorrect.
- Calculates the total score out of 5.
- Displays a performance message based on the final score.

## Technologies Used
- Python 3

## Concepts Used
- Variables
- Input and Output
- Conditional Statements (if, elif, else)
- String Methods (lower())
- Comparison Operators
- Arithmetic Operators

## How to Run
1. Download the Python file.
2. Open it in VS Code or any Python IDE.
3. Run the program.
4. Answer all 5 questions.
5. View your final score!
